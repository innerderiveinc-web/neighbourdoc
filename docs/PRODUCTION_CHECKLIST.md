# Production Checklist

## Healthcare Compliance

- Consent checkbox and timestamp before consultation
- Privacy policy and terms pages
- Telemedicine disclaimer
- Emergency symptom blocking
- Doctor registration verification
- Prescription access restriction
- Audit logs for sensitive actions
- Data deletion request process

## Security

- OTP rate limiting
- Role-based authorization
- Encrypted database storage
- Secure file upload
- Webhook signature verification
- Admin and doctor route protection
- Partner organization scoping
- Secrets stored outside source code

## Payments

- Razorpay order creation
- Razorpay payment verification
- Razorpay webhook handling
- Refund-ready payment states
- Doctor earning ledger
- Payment reconciliation report

## Operations

- SLA breach alerts
- Doctor performance dashboard
- Complaint management
- Refund management
- City/locality management
- Factory/society partner management
- Daily revenue reports
- Exportable reports

## Launch Plan

1. Pilot with 2 verified doctors and 1 factory or society.
2. Manually review first 50 consultations.
3. Enable WhatsApp templates after provider approval.
4. Enable organization billing after patient flow stabilizes.
5. Add diagnostics and medicine delivery integrations after retention is proven.
